# Engineering Of Machine Learning Urfu
This repository contains solutions to assignments and practical tasks from the "Engineering of Machine Learning" Master's (Magistracy) program at Ural Federal University (URFU). The materials demonstrate implementations of various machine learning concepts, algorithms, and techniques covered throughout the course curriculum.
These solutions are shared as educational resources for fellow students, researchers, and anyone interested in machine learning engineering at an advanced academic level. Each folder corresponds to specific coursework assignments, complete with problem statements and detailed solutions.
Feel free to explore, learn from, or contribute to this collection of machine learning engineering materials.

### Folder structure
#### big-data-system-development/
Discipline: Big Data System Development
Solutions for assignments related to developing systems capable of processing and analyzing large-scale datasets, including distributed computing frameworks and big data architectures.
#### collab-notebooks/
Collection of collaborative Jupyter notebooks used across various courses, containing code examples, data exploration, and model implementations.
#### data-storing-and-management/
Discipline: Data Storing and Management
Tasks focusing on database design, data warehousing, efficient data storage solutions, and management systems for machine learning applications.
#### deep-learning-python/
Discipline: Deep Learning with Python
Implementations of neural networks and deep learning models using Python libraries like TensorFlow or PyTorch, covering architectures such as CNNs, RNNs, and transformer models.
#### development-of-systems-analyzing-big-data/
Discipline: Development of Systems for Big Data Analysis
Projects related to building end-to-end systems for analyzing large datasets, including data ingestion, processing pipelines, and visualization components.
#### linux-course/
Discipline: Linux for Data Science/ML Engineering
Materials covering Linux fundamentals, shell scripting, environment setup, and command-line tools essential for machine learning engineering.
#### math-basics-of-machine-learning/
Discipline: Mathematical Foundations of Machine Learning
Assignments exploring the mathematical concepts underpinning machine learning algorithms, including linear algebra, calculus, probability, and statistics.
#### math-basics-of-machine-learning-III/
Discipline: Advanced Mathematical Foundations of ML
Advanced mathematical topics in machine learning, likely building upon the foundations covered in earlier courses.
#### natural-language-processing-III/
Discipline: Advanced Natural Language Processing
Solutions for complex NLP tasks, possibly including transformer architectures, document understanding, and advanced text generation techniques.
#### neural-networks-ethics/
Discipline: Ethics in Neural Networks and AI
Tasks addressing ethical considerations in neural network development and deployment, bias mitigation, fairness, and responsible AI practices.
#### python-pro-level/
Discipline: Advanced Python Programming
Materials focused on advanced Python techniques specifically relevant to machine learning engineering and production systems.
#### regression-project-semester-2/
A comprehensive project focused on regression analysis techniques, representing culminating work from the second semester of studies.
